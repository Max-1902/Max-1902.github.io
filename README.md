# My portfolio

My personal site, built with plain HTML, CSS and JS. No frameworks.

Live at https://max-1902.github.io/

## Run it locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 (Cmd + Shift + R if changes don't show up).

## What's where

- `index.html` – all the content
- `styles.css` – styling
- `script.js` – scroll animations and the project gallery
- `images/` – illustrations, plus `og.png` for link previews
- `Maximilian_Wojciechowski_CV.pdf` – my CV (just replace the file to update it)

If the domain ever changes, update the `og:url`, `og:image` and canonical link in `index.html`.
